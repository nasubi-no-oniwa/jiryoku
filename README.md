# 字力（じりき）

字を1つえらんで、手本なしで自分の手で書く。書いた形がそのまま体になり、漢ノ字・地元の最強と同じしくみでぶつかり合う全自動の1対1。
漢ノ字の「字をばらして組み替える」も入っている（画は回せない）。同じ作品どうしなら、どの端末でも必ず同じ結果になる。

## 強さ
- 能力は5つ（体力・攻撃・防御・鋭さ・速さ）で最大150。合計が総合パワー
- 素質：手本の字の形から（約1万2千字の中の順位を 10〜130 に）。`js/shape.js` の `SH.scale`
- 書いた字：素質 × 再現度の効き（`js/judge.js` の `JD.power`。90%以上でほぼ全力、70%で7割）＋ 書き方のくせ（`JD.mods`。配分だけ変える）
- 総合が動くのは、再現度・書き順（体力+10）・線のなめらかさ（防御+6〜-20）だけ
- 組み替えた作品：素質 × 0.70（`SH.KUMI`）。元の字のまま（手本）は × 0.85
- 左右のかたよりは、試合で体が回る（`js/sim.js` の lean）
- 書く速さで線の太さが変わる（`SH.radii`）
- ※強さの数字を変えると、同じ作品どうしでも結果が変わります

## 作品の文字列
- 書いた字：`w` ＋ 字形 ＋ 字 `:` x,y,t（tは1/100秒）… `;` 次の画…
- 組み替え：字形 ＋ 字 `:` 画,x,y,向き `;` …

## データベース（Firebase：otokonoji を字力が使う）
- `jr_chal/{合言葉}`：{ w, t, wn, ln, u, n（名前）, ch（字） }　番付は wn の順
- `jr_res/{合言葉}/{id}`、`jr_last`・`jr_rlast`（連投の制限）、`jr_acct`（引き継ぎ）、`jr/{部屋}`（部屋番号で対戦）、`qm`・`pres`（だれかと対戦）
- `database.rules.json` を上げると、自動で反映される（`.github/workflows/rules.yml`、鍵は OTOKONOJI_SERVICE_ACCOUNT）
